Plugin

Definição em JSON: parâmetros (tipos texto, numero, com, segredo), arquivos e passos com verificação (codigo_zero, contem, nao_contem, regex) e em_falha (parar ou continuar). No script, $env:HM_ARQUIVOS é a pasta com os arquivos baixados.

Integração com o gestor de OS (opcional)

Ligada, os pedidos de ajuda dos clientes viram chamados no gestor (triagem), a aba Fila mostra os chamados abertos e cada atendimento encerrado atualiza o chamado com o resumo e o relatório.

Site de downloads

Página pública para o cliente baixar o programa. O arquivo já sai configurado com este servidor. Cada empresa (grupo) tem também um link próprio, que coloca o computador direto no grupo.

Análise de falhas por IA (opcional)

Quando um plugin falha, o técnico pode pedir à IA (Claude) a causa provável e a correção sugerida. A IA só sugere: nada é executado sem o técnico. A saída do comando é enviada à API da Anthropic (segredos ficam mascarados).
